🧭 Mentor–Contributor Matching System

A hackathon-built system designed to improve how contributors are mapped to the right mentors on Decode, an existing platform created by students of Newton School of Technology.

🚀 Problem Statement

On community-driven platforms like Decode, new contributors often struggle to:

Find the right mentor

Get relevant guidance early

Avoid friction during onboarding

This mismatch can slow down contributions and reduce overall engagement.

💡 Solution

We built a mentor–contributor mapping system that helps route incoming contributors to the most suitable mentors based on relevance, improving:

Guidance quality

Contributor experience

Efficiency in collaboration

The system was designed and developed as part of a hackathon, focusing on rapid prototyping and practical usability.

🛠️ Tech Stack

Frontend: React / Next.js

Backend: Node.js / Express

Database: MongoDB

Other: REST APIs, GitHub, Hackathon tooling

⚙️ Key Features

Contributor onboarding flow

Mentor matching logic based on predefined criteria

Simple and scalable system design

Built with extensibility in mind for future improvements
